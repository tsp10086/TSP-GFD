# Dataset access

Reddit, Instagram and AmazonVideo are distributed as part of the CAMERA benchmark. Obtain the datasets from the original provider and comply with the applicable licence.

The original CAMERA README lists the dataset download:
https://drive.google.com/file/d/1z75C7Cul7z4SYNhyZn6Jit7cY18xFbEA/view

Node ordering and processing must be checked against the exact data used in the experiments.
